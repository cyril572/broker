# Northstar Brokerage Dashboard

A responsive React dashboard for portfolio performance, market snapshots, holdings, a watchlist, transaction history, trade previews, and support chat.

## Run locally

From the `broker-app` directory:

```sh
npm install
npm run dev
```

Vite prints the local address when the development server starts. Use `npm run lint` and `npm run build` to check the project.

## Demo behavior

Portfolio and market figures are illustrative. Trade actions only show a preview; they do not place orders. The support chat is a local UI demo with scripted replies and is not connected to an agent or chat service. Live quotes, account data, trading, and real-time customer support require secure backend services and provider integrations.
